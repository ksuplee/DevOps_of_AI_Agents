# DevOps of AI Agents — 실습 저장소

위키독스 책 **[AI 에이전트 개발과 운영](https://wikidocs.net/book/20745)**(A권)의 실습 자료 저장소입니다.

- **실습 환경**: Google Colab · Python · Hugging Face `transformers` · 오픈웨이트 모델(Qwen2.5, ko-sroberta 등)
- **여는 법**: Colab에서 `파일 > 노트 열기 > GitHub` → `ksuplee/DevOps_of_AI_Agents` 선택
- **번호 체계**: `MM-NN_제목` (MM=장 번호, NN=절 번호)
